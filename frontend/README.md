# React frontend  Install dependencies with `npm install`, then run `npm run dev` (http://localhost:3000). Set `VITE_API_URL=http://localhost:8003/api` in `.env`.  Public pages are separated into individual React files and matching SCSS files. Blog and Service content is fetched from the Express API; start and seed the backend to see cards. Images and business details are placeholders. Vite's React SPA should use a hosting fallback to index.html for client routes.  The Admin feature will be merged separately on the `feature/admin-panel` branch.
